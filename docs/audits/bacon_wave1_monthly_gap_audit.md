Risk-Adjusted Performance Measurement* (2nd ed.), carried out on the source code
**before** any change, as required by the implementation brief. The live code,
not the manual, decided what exists.

## Formula validation and flagged ambiguities

The book was not available, so no formula could be checked against the printed
page and no worked example from the book was replicated. The implementation
follows the expressions in the brief exactly; where they leave a choice open,
the choice is recorded rather than guessed silently:

1. **Bias ratio standard deviation.** The brief says "monthly return standard
   deviation"; OpenFactsheet uses the sample estimator (n − 1) of decision 0003,
   as the brief's notation specifies. If Bacon intends the population estimator
   the band is slightly narrower.
2. **Bias ratio intervals.** Implemented exactly as printed (closed on both
   sides; a zero return counted in numerator and denominator; returns equal to
   ±s counted). The number of zero returns counted twice is reported in the
   result details.
3. **Skewness-kurtosis ratio estimators.** Bacon works with population moments;
   the brief requires the existing canonical estimators, so the ratio is
   G1 / (G2 + 3). The PerformanceAnalytics population-moment value g1 / b2 is
   recorded as known difference 22 and pinned by a test.
4. **Relative mean difference sign.** The signed mean is used as printed; zero
   mean is undefined and negative values are documented.
5. **Volatility skewness target.** The package target τ = 0
   (`lower_partial_moments.target`, `policy/defaults.py:65`) with full-sample
   denominators (decision 0016), which cancel in the ratio.
6. **Page and equation numbers** are those of the brief and were not verified
   against the book.

## Out of scope / deferred (from the brief)

| Item | Reason |
|---|---|
| Relative skewness / kurtosis, information-ratio variants, up/down number and percentage ratios, bull/bear beta variants, active drawdown, further capture measures | Require a benchmark; monthly portfolio returns alone do not contain one. |
| MAD reward ratio, Gini reward ratio, adjusted Sharpe variants, Treynor / M² variants | Require a risk-free rate or another return series; treating 0 as an observed risk-free return needs separate methodological approval. |
| Bond duration / convexity, active share, holdings-based, high-frequency and intramonth measures, trade-level execution metrics | Require data the package does not receive. |
| Variability skewness sqrt(VS) | Monotonic transform of `volatility_skewness`; documented as an alias only. |
| Standalone UPM2 / LPM2 | Intermediate quantities; sqrt(LPM2(0)) is already the per-period downside deviation. |
| Winsorized mean | Alters the data and can mask real tails. |
| Any metric already in the 97-metric catalog | Would be a duplicate. |
| Conditional tail gain, Hurst exponent, K-ratio, prospect-theory ratios, more involved tail statistics | Deferred for separate review: high estimation variance on short monthly histories. |

## Result

97 → 102 canonical metrics. The increment is exactly `gini_mean_difference`,
`relative_mean_difference`, `skewness_kurtosis_ratio`, `bias_ratio` and
`volatility_skewness`. Every golden report keeps all 97 pre-existing metric
results (values, statuses, confidence, warnings, relative order) and
interpretations identical (compared as parsed JSON against `HEAD`); only the five new ids and their
interpretations are added, with no NaN or Infinity in any JSON.
