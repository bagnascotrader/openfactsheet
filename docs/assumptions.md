# Canonical assumptions — methodology 0.1.0

This page answers each methodological question listed in CLAUDE.md section 41
for methodology **0.1.0**. The machine-readable source of truth is
`src/openfactsheet/policy/defaults.py` (`ofs.methodology()` returns it, and
every report embeds it). Rationale and library comparisons are in the
[decision notes](methodology/decisions/README.md).

Items marked **Deferred** have no canonical answer yet; the report's behavior
in those cases is described so that nothing is hidden.

| Question | Methodology 0.1.0 answer | Decision |
|---|---|---|
| Arithmetic vs geometric annual return | Headline annualized return is geometric (CAGR by observation count). The arithmetic `P x mean` is reported separately as `annualized_arithmetic_mean`. | [0004](methodology/decisions/0004-annual-return.md) |
| Sample vs population standard deviation | Sample (n − 1) everywhere. | [0003](methodology/decisions/0003-standard-deviation.md) |
| Annualization under serial correlation | The canonical annualized ratios keep square-root-of-time scaling (never silently corrected). Beside them, the one-year variance ratio and Lo's (2002) serial-correlation-adjusted Sharpe ratio (horizon q = round(P), sample autocorrelations, at least two years of data) show the size of the bias. | [0029](methodology/decisions/0029-serial-correlation-and-annualization.md) |
| Risk-free treatment | 0% per period for every excess-return metric, disclosed on each metric. Currency is never inferred from the locale. | [0005](methodology/decisions/0005-risk-free-rate.md) |
| Sortino MAR / target | 0% per period. | [0006](methodology/decisions/0006-sortino-downside-deviation.md) |
| Omega threshold | 0% per period, simple empirical estimator `sum(max(r, 0)) / sum(max(-r, 0))`, not annualized. | `policy/defaults.py` (`omega`) |
| VaR confidence | 95%, historical, per observation period. | [0010](methodology/decisions/0010-var-es-quantiles.md) |
| ES confidence | 95%, historical: mean of returns at or below the 5% quantile. | [0010](methodology/decisions/0010-var-es-quantiles.md) |
| Exact quantile interpolation | Linear interpolation (Hyndman-Fan type 7; R and NumPy default). | [0010](methodology/decisions/0010-var-es-quantiles.md) |
| Downside deviation denominator | All n observations (full sample). | [0006](methodology/decisions/0006-sortino-downside-deviation.md) |
| Minimum track record | `minimum_track_record_length` (Bailey & López de Prado 2012): observations needed for the observed Sharpe ratio to exceed 0 at 95% one-sided confidence, keeping skewness and kurtosis; `not_applicable` when the Sharpe ratio is not positive. Independently, confidence labels treat most estimates as `low` below 3 years and `moderate` below 5. | [0019](methodology/decisions/0019-sharpe-ratio-inference.md), [0015](methodology/decisions/0015-minimum-data-policy.md) |
| Sharpe-ratio uncertainty | Non-normal i.i.d. asymptotics on the per-period Sharpe ratio with population skewness and non-excess kurtosis (kurtosis is never ignored). Probabilistic Sharpe Ratio against a reference of 0; standard error of the annualized Sharpe ratio with a two-sided 95% interval. Serial correlation is not modelled (smoothing lowers confidence). The Deflated Sharpe Ratio is **not computable** from a single series because it needs the number of strategies tried. | [0019](methodology/decisions/0019-sharpe-ratio-inference.md) |
| Mean-return uncertainty | Standard error `s / sqrt(n)` with a two-sided 95% Student-t interval (n − 1 degrees of freedom) and a t-test against zero. | [0020](methodology/decisions/0020-mean-inference-and-normality.md) |
| Normality testing | Jarque-Bera with population moments and the asymptotic chi-squared(2) p-value; supplementary diagnostic only. | [0020](methodology/decisions/0020-mean-inference-and-normality.md) |
| Lower-partial-moment targets and denominators | Target 0% per period and full-sample denominator n for Kappa 3, upside potential ratio and downside potential (all per period); semi-deviation uses the sample mean as target, denominator n, annualized by sqrt(P); mean absolute deviation is per period. | [0016](methodology/decisions/0016-lower-partial-moment-ratios.md) |
| Mean difference, shape ratios and bias ratio | Gini mean difference over the n(n − 1) ordered pairs, per period; relative mean difference divides by the **signed** mean (undefined at 0); skewness-kurtosis ratio = G1 / (G2 + 3) with the canonical estimators (undefined when G2 + 3 <= 0); volatility skewness = UPM2 / LPM2 at target 0 with full-sample denominators; bias ratio with the sample standard deviation and closed intervals, a zero return counted on both sides. None is annualized. | [0036](methodology/decisions/0036-bacon-wave1-monthly-measures.md) |
| Drawdown-ratio conventions | Burke uses the depths of peak-to-recovery episodes; Sterling = CAGR / (\|max drawdown\| + 10%), the 10% being a disclosed historical convention; Pain ratio = CAGR / Pain Index; full history, rf = 0. Payoff ratio excludes zero-return periods. | [0017](methodology/decisions/0017-drawdown-ratios-burke-sterling-pain.md) |
| Parametric VaR | Gaussian and Cornish-Fisher VaR at 95% with population moments (Boudt, Peterson & Croux 2008); supplementary and model-dependent; the historical VaR remains the headline tail estimate. | [0018](methodology/decisions/0018-parametric-var.md) |
| Benchmark alignment | Intersection of calendar periods (monthly/quarterly/yearly) or exact dates (daily/weekly); never filled; overlap disclosed; different frequencies raise an error. | [0012](methodology/decisions/0012-benchmark-alignment-and-relative-metrics.md) |
| Factor models | Only with factor returns supplied by the caller (never downloaded). A column named `RF` is subtracted from fund returns; otherwise the risk-free rate is 0%. One return scale for all factor columns. OLS with Newey-West standard errors (lag floor(4 (m/100)^(2/9)), Bartlett kernel, no prewhitening, small-sample factor, Student t); 95% intervals; periods missing for any series are dropped, never filled. | [0028](methodology/decisions/0028-factor-models.md) |
| Charts | Eight fixed charts over the full history: linear scales, zero baselines for bars, symmetric heatmap scale, partial years labelled, every return in the histogram, benchmark only on the aligned overlap; the 10 deepest drawdown episodes tabulated. | [0026](methodology/decisions/0026-canonical-charts.md) |
| Missing values | Never replaced by zero or forward-filled. Leading and trailing missing values are trimmed; interior missing values are removed, counted and disclosed, and appear as missing expected periods. Wealth-path and annualized metrics are capped at `moderate` confidence when gaps exist. | [0002](methodology/decisions/0002-annualization-and-frequency.md), [0015](methodology/decisions/0015-minimum-data-policy.md) |
| PDF factsheets | Embedded text only; values assigned to month columns by horizontal position; every year with a YTD / total cell must reconcile (compounded, within worst-case rounding) or the table is refused; blank months inside the history are missing, never zero; scanned PDFs refused. | [0030](methodology/decisions/0030-pdf-ingestion.md) |
| OCR (screenshots, scanned PDFs) | Local engine only (RapidOCR with bundled models, or Tesseract); cells below 0.90 confidence refuse the table; every year needs a reconciling YTD / total cell; documented character repairs and up to three inferred month headers are recorded and lower confidence. | [0031](methodology/decisions/0031-ocr-ingestion.md) |
| Fund profile of a document | Fixed fields with evidence; identifiers validated by check digit and never corrected, label-only codes only after their label; the profile never changes a metric and a named benchmark is never used as benchmark returns. | [0032](methodology/decisions/0032-identifiers-and-fund-profile.md) |
| Benchmark returns printed in a document | Returned by `ofs.load()` as a separate series, never used automatically; `analyze()` uses the fund series and says so. Relative rows are ignored. The returns table is attributed to a share class only by printed evidence; otherwise ambiguous. | [0033](methodology/decisions/0033-share-classes-and-table-roles.md) |
| Monthly table partial years | Empty cells are missing, never zero. Empty cells after the last reported month (future months) are trimmed; empty cells inside the history are interior missing values. Annual total columns (YTD, Year, Total) are ignored for calculation and the omission is recorded as a transformation. Calendar-year statistics use **complete years only** (all 12 months; all 4 quarters; daily/weekly within 7 days of both year ends); partial years are listed in details and warnings and never used. | `input/monthly_table.py`, [0023](methodology/decisions/0023-calendar-year-statistics.md) |
| Drawdown tail and entropic measures | DaR and CDaR at 95% on the compounded drawdown path D_1..D_n with the historical VaR / ES estimators (linear quantile; mean at or below it); EDaR and EVaR at 95% by one-dimensional convex minimization. With 20 or fewer observations EVaR equals the worst period and EDaR the maximum drawdown. | [0021](methodology/decisions/0021-drawdown-tail-and-entropic-measures.md) |
| Modified Expected Shortfall | Cornish-Fisher ES (Boudt, Peterson & Croux 2008) at 95% with population moments and the full expansion; supplementary and model-dependent; a note is attached when it is less severe than the modified VaR. | [0022](methodology/decisions/0022-modified-expected-shortfall.md) |
| Rolling-window convention | One-year windows of round(P) consecutive observations, advanced one observation at a time; every start date is used; never user-selected. | [0024](methodology/decisions/0024-rolling-one-year-windows.md) |
| Drawdown durations and recovery | Durations in observation periods from peak to recovery; open episodes count to the last observation in the average duration (lower bound) and are excluded from the average recovery time. Recovery factor = compounded cumulative return / \|max drawdown\|. | [0025](methodology/decisions/0025-episode-durations-and-path-summaries.md) |
| Return scale detection | Deterministic classifier: declared scale, `%` labels, then median absolute value against frequency-dependent bounds; ambiguous cases raise `AmbiguousReturnScaleError` instead of guessing. | [0013](methodology/decisions/0013-return-scale-detection.md) |
| -100% return behavior | Valid (total loss). Wealth becomes zero, cumulative return and CAGR are -100%, maximum drawdown is -100%, and a critical finding plus metric warnings are shown. | [0001](methodology/decisions/0001-return-type.md), [0007](methodology/decisions/0007-drawdown-conventions.md) |
| Returns below -100% | Impossible for ordinary simple returns: kept (never clipped), flagged as critical, and every wealth-path metric is `not_applicable`. Moment-based metrics are still computed. | [0001](methodology/decisions/0001-return-type.md) |
| Non-finite return behavior | Infinite values raise `InputError` before any calculation. NaN means a missing observation (see above). No metric result can hold NaN or infinity: undefined values are `not_applicable` with a reason, unexpected failures are `error` with a reason. A result that overflows to plus or minus infinity (a denominator non-zero but below floating-point resolution, e.g. a single subnormal loss) is reported as `not_applicable` with an overflow explanation; a NaN result remains `error`. | [0001](methodology/decisions/0001-return-type.md), `metrics/engine.py` |
| Numerically constant returns | Shape statistics built on moments (skewness, kurtosis, Jarque-Bera, Cornish-Fisher VaR / ES, Sharpe-ratio inference) are `not_applicable` when the returns are identical or their variance is at or below floating-point resolution (`ptp(r) == 0` or `m2 <= 16 (eps · max\|r\|)^2`), instead of reporting rounding noise. | `metrics/context.py` (`_standardized_moment`) |
| Compounding after total loss | Wealth stays at zero; later returns cannot rebuild it and the drawdown never recovers. | [0007](methodology/decisions/0007-drawdown-conventions.md) |
| Irregular time series | Never annualized: annualized metrics are `not_applicable` with a reason. Non-annualized metrics are computed. | [0002](methodology/decisions/0002-annualization-and-frequency.md) |
| Undated values | Frequency is unknown and nothing is annualized unless the caller declares the frequency; a declaration is recorded and warned. | [0002](methodology/decisions/0002-annualization-and-frequency.md) |
| Crypto / non-business-day data | Daily series with weekend observations use 365 periods per year; business-day series use 252. **Deferred:** mixed calendars (e.g. a 365-day fund against a 252-day benchmark, which currently aligns only on common dates), intraday data, and holiday calendars by exchange. | [0002](methodology/decisions/0002-annualization-and-frequency.md) |
| Frequency changes within a series | Detected as irregular when fewer than half of the spacings equal one period; no resampling. **Deferred:** splitting a history into regular segments. | [0002](methodology/decisions/0002-annualization-and-frequency.md) |
| Drawdown starting point | Initial wealth 1 counts as the first peak, so a first-period loss is a drawdown. | [0007](methodology/decisions/0007-drawdown-conventions.md) |
| Skewness / kurtosis estimators | Bias-corrected G1 and excess G2. | [0011](methodology/decisions/0011-skewness-kurtosis.md) |
| Smoothed returns | Diagnosed (lag-1 autocorrelation with significance), warned and downgraded; never unsmoothed. | [0014](methodology/decisions/0014-smoothing-risk.md) |

## What the caller may and may not set

The canonical API has no parameters for windows, thresholds, confidence
levels, target returns, risk-free rates or metric subsets. The only optional
arguments describe the input when the data cannot establish it:

- `return_scale="decimal" | "percent"` — only needed when detection reports ambiguity;
- `frequency=` — the observation frequency of undated values (checked against dates when dates exist);
- `benchmark=` — an explicitly supplied benchmark; none is ever inferred;
- `name=` — a display name.

Declarations are recorded in the input diagnostics and warned on the affected
metrics.
