# Reference manual

The OpenFactsheet reference manual is a CRAN-style PDF generated from the code
([decision 0034](../methodology/decisions/0034-reference-manual.md)). Nothing in it is
written by hand: the functions and classes come from docstrings, the metrics from the
registry, and the rest from the documents in `docs/`.

## Build

```bash
pip install -e ".[dev,docs]"
python scripts/build_manual.py          # docs/manual/build/openfactsheet-manual.pdf
python scripts/build_manual.py --check  # compile to a temporary file only
```

The build uses no network and no system fonts. The same sources give the same PDF.
It fails if a formula does not compile, if an internal link has no target, or if a
topic lacks its named destination.

## Layout

| Path | Contents |
| :-- | :-- |
| `openfactsheet-manual.typ` | Main template: title page, parts, bibliography, index |
| `lib/style.typ` | Page style and helpers (Markdown with math, sections, anchors) |
| `lib/topics.typ` | Renderers for API topics, metric topics, documents, bibliography, index |
| `data/*.json` | Generated by `scripts/generate_docs.py` (checked by `--check`); do not edit |
| `packages/preview/mitex/0.2.7` | Vendored [MiTeX](https://github.com/mitex-rs/mitex) (Apache-2.0): LaTeX formulas |
| `packages/preview/cmarker/0.1.10` | Vendored [cmarker](https://github.com/SabrinaJewson/cmarker.typ) (MIT): Markdown |

The vendored packages keep their license files. To update one, replace its directory
with the release from `https://packages.typst.org/preview/<name>-<version>.tar.gz`,
update the imports in `lib/style.typ`, and rebuild.

## Link targets

Every topic is a PDF named destination, so
`openfactsheet-manual.pdf#nameddest=<target>` opens it:

| Target | Topic |
| :-- | :-- |
| `metric-<id>` | a metric, e.g. `metric-sharpe_ratio` |
| `api-<name>` | a function, class, exception or constant, e.g. `api-analyze` |
| `decision-<nnnn>` | a methodology decision, e.g. `decision-0008` |
| `doc-<name>` | a document, e.g. `doc-criteria` |
| `category-<id>` | a group of metrics, e.g. `category-drawdown` |
| `ref-<key>` | a bibliography entry, e.g. `ref-sharpe1966` |
