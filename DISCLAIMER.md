# Important information and disclaimers

This file is the single, version-controlled source of OpenFactsheet's
English-language disclosure. The README, the documentation, the reference
manual, the generated reports and the website reuse or link to this text rather
than keeping their own copies. A test (`tests/unit/test_disclaimer.py`) fails if
the short notice below drifts from the copy used in the README and the reports.

## Short notice

Where the full disclosure would be disruptive (report headers, comparison
output, small screens), OpenFactsheet uses this short notice, always with a link
to this page:

> For information and education only — not investment advice. Investing involves risk; past performance does not predict future results. Verify results and consult a qualified financial adviser.

The short notice does not replace context-specific warnings: every report also
carries its data-quality findings, confidence labels, assumptions and the
reasons a metric is unavailable.
